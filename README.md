## 快速开始

### 安装

#### Windows
 从(https://github.com/sxzhaot/marktext_cn/releases) 下载解压

### 首次运行

启动 MarkText 后，您将看到一个空白编辑器窗口。您可以：

- 直接开始输入 Markdown 文本
- 通过「文件」菜单打开现有 Markdown 文件
- 拖拽 Markdown 文件到编辑器窗口

## Markdown 语法

### 基础语法

#### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

#### 强调

```markdown
*斜体文本*
**粗体文本**
***粗斜体文本***
~~删除线文本~~
```

#### 列表

**无序列表：**
```markdown
- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2
```

**有序列表：**
```markdown
1. 第一项
2. 第二项
3. 第三项
```

**任务列表：**
```markdown
- [x] 已完成任务
- [ ] 待办任务
```

#### 链接和图片

```markdown
[链接文本](https://example.com)
![图片描述](image.png)
```

#### 代码

**行内代码：**
```markdown
这是 `代码` 示例
```

**代码块：**
<pre>
```javascript
function hello() {
  console.log("Hello, World!");
}
```
</pre>

#### 引用

```markdown
> 这是一段引用文字
> 可以换行继续
```

#### 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| 内容   | 内容 |   内容 |
```

### 扩展语法

#### 数学公式

**行内公式：**
```markdown
这是行内公式 $E = mc^2$
```

**块级公式：**
```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

#### 脚注

```markdown
这是一个脚注引用[^1]

[^1]: 这是脚注的内容
```

#### 上标/下标

```markdown
H~2~O (下标)
E = mc^2^ (上标)
```

## 高级功能

### 图片上传

MarkText 支持多种图片处理方式：

1. **复制到本地文件夹**：图片自动复制到指定文件夹
2. **上传到云端**：支持 PicGo、GitHub 等上传服务
3. **保持原始位置**：使用文档同目录的图片

配置路径：「偏好设置」→「图片」

### 主题切换

MarkText 提供多种主题：

- Light（浅色）
- Dark（深色）
- Graphite（石墨灰）
- Material Dark（材质深色）
- Ulysses
- One Dark

配置路径：「偏好设置」→「主题」

### 自动保存

启用自动保存后，编辑器会自动保存您的更改：

1. 打开「偏好设置」→「通用设置」
2. 启用「自动保存」
3. 设置自动保存延迟时间

### 拼写检查

MarkText 内置拼写检查功能：

1. 打开「偏好设置」→「拼写检查」
2. 启用「启用拼写检查」
3. 选择检查语言

## 偏好设置

### 通用设置

- **自动保存**：自动保存文档更改
- **窗口**：标题栏样式、缩放级别
- **侧边栏**：大纲换行、文件排序
- **启动行为**：启动时打开默认目录或空白页
- **语言**：界面语言（简体中文/English）

### 编辑器设置

- **字体**：选择编辑器字体和大小
- **代码块**：代码块字体设置
- **写作行为**：自动配对括号、引号等
- **文件表示**：缩进大小、换行符、编码
- **文本方向**：从左到右/从右到左

### Markdown 设置

- **列表**：列表标记样式、缩进方式
- **扩展**：脚注、上标/下标、Pandoc 扩展
- **兼容性**：HTML 渲染、GitLab 兼容模式
- **图表**：序列图主题

### 图片设置

- **插入动作**：插入图片后的默认操作
- **文件夹设置**：全局/相对图片文件夹
- **上传器**：配置 PicGo、GitHub 等上传服务

## 常见问题

### 如何切换语言？

1. 打开「偏好设置」→「通用设置」
2. 在「界面语言」下拉菜单中选择「简体中文」
3. 部分界面需要重启应用生效

### 如何更改主题？

1. 打开「偏好设置」→「主题」
2. 选择您喜欢的主题
3. 可选择「启动时调整主题」跟随系统

### 如何使用图片上传功能？

1. 打开「偏好设置」→「图片」
2. 配置图片插入后的行为
3. 如需上传到云端，配置 PicGo 或 GitHub

### 如何启用自动保存？

1. 打开「偏好设置」→「通用设置」
2. 启用「自动保存」
3. 设置保存延迟时间

### 文件编码问题

如果打开文件出现乱码：
1. 打开「偏好设置」→「编辑器」
2. 启用「自动检测文件编码」
3. 或手动选择正确的编码格式

### 如何使用数学公式？

MarkText 支持 LaTeX 数学公式：

- 行内公式：使用 `$公式$`
- 块级公式：使用 `$$公式$$`

### 如何导出 PDF？

1. 选择「文件」→「导出」→「PDF」
2. 选择导出位置
3. 等待导出完成
